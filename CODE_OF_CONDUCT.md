# Code of conduct

Amp is a small project for people who like audiobooks and tidy software.

- Be direct, be kind, assume good faith.
- Critique the code, not the person.
- No harassment, no personal attacks, no discriminatory language.
- Keep issues and pull requests on topic.

Maintainers may edit or remove comments and contributions that break these
rules, and may block accounts that persist. If something needs a maintainer's
attention, open an issue titled "conduct" or email the address in the repository
profile.
