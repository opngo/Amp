// playback

      
Built on the Web Audio graph, not a wrapper around it

      

        Audio goes element → ten biquad filters → preamp → panner → analyser →
        output gain — which is what makes the equalizer and device switching
        real instead of decorative.
      

    


    

      

      

    

  


  


  
  

    

      
// acquisition

      
Find it, download it, listen to it

      

        Amp never bundles a torrent client and never scrapes in the background.
        It searches when you ask, hands the magnet to qBittorrent, and imports
        the result once the download finishes.
