# Assets

Brand assets for Amp. Everything here is generated by `scripts/make-icons.mjs`,
so edit the script rather than the files.

| File | Size | Used by |
| --- | --- | --- |
| `logo.svg` | vector | README, website, documentation |
| `icon.png` | 512 px | GitHub social preview, README |

The runtime copies live with the code that ships them:

| File | Size | Used by |
| --- | --- | --- |
| `apps/desktop/resources/icon.png` | 1024 px | electron-builder app icon |
| `apps/desktop/resources/tray.png` | 32 px | tray icon |
| `apps/desktop/resources/tray@2x.png` | 64 px | tray icon on retina displays |
| `apps/website/public/icon.png` | 512 px | landing page favicon and hero |
| `apps/desktop/resources/icon.svg` | vector | the same source, kept next to the app icon |
| `apps/desktop/resources/entitlements.mac.plist` | - | macOS signing entitlements |

## The mark

A rounded square filled with the Amp gradient (`#6c8cff` to `#ff9ecb`) and five
white bars: a level meter, which is also why the visualizer defaults to an
circles riding the audio around the cover rather than a wall of bars. Corners are 22 percent of
the tile, bar widths 7.5 percent, gaps 3.5 percent, and the bar heights follow
0.34, 0.58, 0.8, 0.58, 0.34 so the shape reads as a sound source rather than a
bar chart.

The same drawing is available as a React component, `AmpLogo` in `packages/ui`,
which takes `size`, `mono` (for one-colour contexts such as a toolbar) and
`title`.

```bash
npm run icons
```
